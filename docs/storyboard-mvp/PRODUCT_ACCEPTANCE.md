# 单场景分镜工作台：产品验收口径（SB-01）

状态：已冻结（2026-10-06）。本文件与 `API_CONTRACT.md`、`schemas/`、`fixtures/` 是 SB-03～SB-06 的共同输入。

## 本轮范围

输入是一份已解析剧本中的一个场景。用户选择 4～8 个镜头（默认 6）并可填写不超过 1,000 个规范化 LF 字符的创作要求。生成结果是独立保存的文字分镜草稿；它绝不修改 `ScriptVersion.rawText`、解析场景或原有剧本版本。

用户可编辑景别、运镜、画面、对白、声音、预计时长、图像 Prompt、视频 Prompt，可调整既有镜头顺序、保存、重做一个镜头并采纳/放弃候选。首版不支持人工增删镜头、图像/视频生成、长篇自动拆场、迁移到新剧本版本或多人协作。

核心按钮文案：`生成分镜`、`保存分镜`、`重新生成此镜`、`采纳候选`、`放弃候选`、`复制图像 Prompt`、`复制视频 Prompt`、`导出 Markdown`。

## 有用分镜与严重错误

一份结果只有在镜头数准确、每镜清楚可拍、每个 `sourceQuote` 能在冻结场景文本中定位、两个 Prompt 与画面一致时，才可进入人工质量评价。评价表见 `samples/EVALUATION_RUBRIC.md`。

以下任一情况是严重错误，不能因 JSON 合法而通过：

- 信被拆开、被阅读，或林舟/许晴的收信顺序被改变；新增和解、离别或其他结局。
- 让人物在尚未完成的动作之后才持有道具，或让手电、文件夹、门锁发生不连续变化。
- 无对白场景凭空写出对白、旁白或未在原文发生的情节。
- 改写或增补关键原文对白，或 `sourceQuote` 不属于来源快照。
- 漏镜、镜头数错误、缺少任一 Prompt，或用泛化 Prompt 不能指导该镜拍摄。

## 非质量验收边界

fixtures 和 mock 只验证契约、流程与异常，不构成真实模型质量验收。SB-12 必须以配置好的真实 provider 对以上三个样本各至少生成两次，并独立记录输出、时延、用量及人工评价。
