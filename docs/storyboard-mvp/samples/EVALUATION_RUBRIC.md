# 固定样本人工评价表

对每一镜填“直接用 / 小改可用 / 需要重做”，并记录具体镜号与证据。

| 维度 | 检查问题 | 失败示例 |
| --- | --- | --- |
| 剧情忠实度 | 是否改变关系、结局、关键对白或固定事实？ | 未拆的信被读出内容。 |
| 动作与道具连续性 | 前一镜的动作、位置和持有状态是否支持后一镜？ | 信在放到茶几前已到许晴手中。 |
| 镜头可拍性 | 是否能明确知道拍谁、拍什么动作、何种镜头？ | “气氛紧张”而没有可见画面。 |
| Prompt 一致性 | 图像/视频 Prompt 是否与该镜人物、道具、动作一致？ | 无信的 Prompt 描述读信。 |
| 来源可核对性 | sourceQuote 是否在冻结场景原文出现并支持该镜？ | 引用原文不存在的动作。 |

结构合法仅是前置条件；任意严重错误都判为“需要重做”。
