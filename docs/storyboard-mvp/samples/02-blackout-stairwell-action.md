# 样本 02：停电楼梯（连续动作）

```text
INT. 医院安全楼梯 - 夜

楼道突然停电。陈默按亮手机手电，另一只手夹着蓝色文件夹。他刚迈下一级台阶，文件夹滑落，纸页散到下一层平台。

身后的苏岚抓住扶手，没有移动。

苏岚：别下去，门锁上了。

陈默蹲在台阶上，用手电照向平台。他没有碰那扇门。

苏岚把自己的钥匙递给陈默。陈默接过钥匙，仍蹲在原地，先把散页压回蓝色文件夹。

远处应急灯亮起一盏。两人看见门锁还扣着。
```

不可改变的剧情事实：停电先发生；陈默始终先持有手机手电和蓝色文件夹；文件夹滑落后纸页散在平台；苏岚先不移动；门始终锁着且陈默没有碰门；钥匙由苏岚交给陈默；最后文件已收回夹中、应急灯只亮一盏。
